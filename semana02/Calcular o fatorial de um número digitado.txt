INP
        STA N

        LDA UM
        STA FAT

LOOP    LDA N
        BRZ FIM

        LDA ZERO
        STA RES

        LDA N
        STA CONT

MULT    LDA CONT
        BRZ FIMMULT

        LDA RES
        ADD FAT
        STA RES

        LDA CONT
        SUB UM
        STA CONT

        BRA MULT

FIMMULT LDA RES
        STA FAT

        LDA N
        SUB UM
        STA N

        BRA LOOP

FIM     LDA FAT
        OUT
        HLT

N       DAT 0
FAT     DAT 0
RES     DAT 0
CONT    DAT 0
UM      DAT 1
ZERO    DAT 0

o usuário vai digitar um número que o programa vai receber pelo comando INP. Esse valor é armazenado na variável N.
Como o lmc não possui multiplicação o resultado é calculado por somas repetidas (4x4= 4+4+4+4). A variável FAT armazena o resultado parcial, enquanto RES e CONT auxiliam na realização das multiplicações.
Após o cálculo, o resultado armazenado em FAT é exibido ao usuário através do comando OUT.
Entrada: 4 → Processamento: 4 × 3 × 2 × 1 → Saída: 24.
